# Sever

VPN на собственном сервере: арендуйте чистый VPS, выполните одну команду и импортируйте полученную ссылку или QR-код в VPN-приложение.

## Быстрый запуск

Целевая система: Ubuntu 22.04, 24.04 или 26.04, Linux x86_64, systemd. Войдите на VPS по SSH от root. Выполните одну команду от root (IP указывать не нужно):

```sh
apt-get update -qq && apt-get install -y -qq curl ca-certificates && curl -fsSL https://raw.githubusercontent.com/gazuinezhaley-tech/sever-vpn/main/install.sh | bash
```

Если вошли как обычный пользователь с sudo:

```sh
sudo bash -c 'apt-get update -qq && apt-get install -y -qq curl ca-certificates && curl -fsSL https://raw.githubusercontent.com/gazuinezhaley-tech/sever-vpn/main/install.sh | bash'
```

Вариант прямого запуска заранее скачанного установщика:

```sh
bash sever-install.run
```

Установщик проверяет архив, автоматически определяет публичный IPv4, при необходимости устанавливает Python и системные утилиты из apt, запускает VLESS/REALITY и выводит ссылку подключения, QR-код и путь к файлам. Домен и сертификат не требуются.

На сервере с sudo запускайте установщик через sudo. Для нестандартной сети можно явно задать адрес: sudo bash sever-install.run --host ВАШ_IP. Для VPS за NAT необходимо также настроить перенаправление TCP-порта 443 у хостинга.

Если UFW активен, установщик разрешает TCP-порт 443. Отдельный сетевой экран в панели хостинга настраивается пользователем. Если нужный порт занят или Sever уже установлен, запуск остановится без перезаписи существующих данных.

## Подключение

Ссылка VLESS/REALITY импортируется в совместимое приложение на iPhone/iPad, Android, Windows, macOS или Linux. На телефоне QR сканируется внутри VPN-приложения. Приложения и системное подтверждение VPN на пользовательском устройстве выполняются пользователем.

Профили: /opt/sever/config/exports/owner/ . Файлы link.txt, qr.png, qr.svg, subscription.txt, xray.json, README.txt. Файлы выдаются только владельцу устройства. xray.json запускает локальный SOCKS5-прокси; для всего устройства нужен режим VPN/TUN совместимого клиента.

## Управление

Введите sever. Меню поддерживает пользователей, включение и отключение, срок доступа, квоту и расход трафика, резервное копирование и восстановление, экспорт профилей. Пункт 15 — выбрать устройство; 16 — QR; 17 — инструкции. Для каждого устройства можно создать отдельного пользователя.

## Проверка и сборка

Python 3.10+. Тесты: python3 -m unittest discover -s tests -v . Сборка релиза: python3 tools/build_release.py . Сборка запускаемого файла и HTTPS-загрузчика: python3 tools/build_installer.py --release-url URL_HTTPS_РЕЛИЗА .

SHA-256 встроенного архива проверяется до выполнения установки, а установщик проверяет манифест файлов. SHA-256 защищает от повреждения; доверие к издателю определяется HTTPS-адресом загрузки. QR-библиотеки и их лицензии включены в src/_vendor; Xray и геоданные включены в vendor. Для исходных файлов третьих сторон сохранены их лицензии.

## Проверки и границы

15 автоматических тестов проходят. Предыдущая версия установщика проверена установкой и восстановлением в изолированных Linux-средах; клиентский профиль проверен реальным HTTPS-запросом через сервер. Автоматическая оболочка также проверена запуском без параметров в отдельной чистой среде systemd-nspawn с изолированной сетью и тестовым публичным адресом. Проверены определение адреса, запуск служб, создание профилей и безопасный отказ при повторном запуске. Это среда на текущем ядре Ubuntu 26.04, а не независимый VPS; автоматическая установка недостающих пакетов и активный UFW в этом тесте не задействованы. Физические телефоны, все версии графических клиентов и сетевые ограничения каждого оператора не проверены.

HTTPS-подписка отключена. Протокол для этого выпуска — VLESS/REALITY. Данные пользователей и ключи генерируются на сервере и не включаются в публичный релиз.
